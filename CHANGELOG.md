# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial template setup
- Automatic versioning workflows for development and main branches

- **Development Branch**: Latest/experimental builds with automatic patch versioning
- **Main Branch**: Production/stable releases with semantic versioning

- **GitHub Releases**: Automatic release creation and asset uploads
- **Workflow Templates**: Production-ready workflows for plugin development
